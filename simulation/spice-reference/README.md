# SPICE Reference Files

This directory contains mode-specific SPICE netlists for the three INCEPT-3 output selections, a pin/node mapping table, and simulation result text. These files provide a text-based circuit reference for inspection and simulator workflows.

- `buck555_mode1.cir` — 3.3 V selection
- `buck555_mode2.cir` — 5 V selection
- `buck555_mode3.cir` — 12 V selection
- `buck555_netlist_table.csv` — element and node mapping
- `RESULTS_ngspice.txt` — recorded simulation measurements
- `buck555_selectable_preliminary.cir` — early single-netlist circuit iteration
